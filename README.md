# Casa de Eventos Alba — sitio web inicial

Sitio estático hecho con HTML, CSS y JavaScript. No usa base de datos ni necesita backend.

## Cómo verlo
1. Descomprime la carpeta.
2. Abre `index.html` con tu navegador.
3. Para desarrollar cómodamente, puedes abrir la carpeta en Visual Studio Code y usar la extensión Live Server.

## Configurar WhatsApp
1. Abre `script.js`.
2. Busca esta línea:
   `const WHATSAPP_NUMBER = "57AQUIELNUMERO";`
3. Reemplaza el texto por el número comercial real con indicativo de Colombia, sin `+`, espacios ni guiones.
   Ejemplo ficticio: `573001234567`.
4. Guarda y prueba los botones.

## Antes de publicar
- Reemplaza las imágenes de ejemplo por fotografías reales de Casa de Eventos Alba.
- Revisa que los servicios y las preguntas frecuentes describan correctamente lo que ofrece la empresa.
- Confirma las zonas de cobertura.
- Las imágenes de ejemplo se cargan desde Unsplash y requieren conexión a internet.
- Puedes publicar el sitio estático en Cloudflare Pages, Netlify o GitHub Pages.

## Archivos
- `index.html`: contenido y estructura de la web.
- `styles.css`: identidad visual y diseño adaptable.
- `script.js`: menú móvil y enlaces de WhatsApp.
